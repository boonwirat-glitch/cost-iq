# SQL สำหรับ Data Team — เปิดฟีเจอร์กำไร (GP) บน Sense + NRR Dashboard

แพ็กนี้มี **2 ไฟล์เท่านั้น** — ไฟล์ไหนไม่อยู่ในนี้ = ไม่ต้องแตะ ไม่เกี่ยวกับงานนี้

ทั้งสองไฟล์คือ **เวอร์ชันเดิมที่ใช้งานอยู่ทุกวันนี้** บวกคอลัมน์กำไร (`margin_ex_vat`)
ต่อท้ายเข้าไป — ไม่มีอะไรถูกลบหรือย้ายตำแหน่ง ปลอดภัยที่จะรันทับของเดิมได้เลย

---

## ทำไมต้องรัน

ทีมฝั่งโค้ด (Sense + NRR Dashboard) เพิ่งเพิ่มฟีเจอร์ "กำไร (GP)" — โชว์กำไรขั้นต้น
(ยอดขาย ลบ ต้นทุนสินค้า) ควบคู่กับยอดขายที่มีอยู่เดิม แต่โค้ดฝั่งเว็บอ่านคอลัมน์กำไร
จาก CSV ที่ **ยังไม่มีอยู่จริง** — ต้องรัน 2 ไฟล์นี้ก่อน ตัวเลขถึงจะขึ้น

**ก่อนรัน:** ทุกจอที่เกี่ยวกับกำไรจะโชว์ข้อความ "ยังไม่มีข้อมูลกำไร" เฉยๆ — ไม่มีอะไรพัง
**หลังรัน:** ตัวเลขกำไรขึ้นเองทันทีในทุกจอ ไม่ต้องแก้โค้ดอะไรเพิ่ม

---

ทับไฟล์เดิมทุกคน) เหมือนขั้นตอนที่ทำอยู่ทุกครั้ง ไม่มีอะไรต่างจากเดิม

## เช็คก่อนอัปโหลด — นับจำนวนคอลัมน์ใน CSV ที่ export ออกมา

วิธีมั่นใจง่ายที่สุดว่ารันไฟล์ถูกเวอร์ชัน: เปิด CSV ที่ยังไม่ผ่าน splitter ขึ้นมา
นับหัวคอลัมน์ (แถวแรก) —

- **`download_skus.csv`** ต้องมี **22 คอลัมน์** (เดิม 20 คอลัมน์ + `margin_ex_vat` +
  `gmv_with_margin` ต่อท้าย 2 คอลัมน์สุดท้าย)
- **`download_upsell_bulk.csv`** ต้องมี **11 คอลัมน์** (เดิม 8 คอลัมน์ + `existing_margin`
  + `total_margin` + `gmv_with_margin` ต่อท้าย 3 คอลัมน์สุดท้าย)

ถ้านับได้น้อยกว่านี้ = รันไฟล์เก่าอยู่ ยังไม่ใช่เวอร์ชันในแพ็กนี้

## สิ่งที่ตั้งใจไว้ในทั้งสองไฟล์ (สำหรับคนตรวจ/แก้ SQL ต่อ)

- **กำไรติดลบต้องรอด** — สินค้าที่ขายขาดทุน (ของล่อลูกค้า) เป็นเรื่องปกติทางธุรกิจ
  ทั้งสองไฟล์ **ไม่มี** `margin_ex_vat > 0` filter ห้ามเพิ่ม filter นี้เข้าไปทีหลัง
  เพราะจะทำให้ฝั่งจอเห็นแต่กำไรที่เป็นบวก ตัวเลขรวมจะเพี้ยน
- **ตัวกรองเดิมของยอดขายไม่ถูกแตะ** — `q3c_upsell_bulk_all_kams_v4.sql` ยังมี
  `gmv_ex_vat > 0` เหมือนเดิมทุกจุด (ตัวนี้กระทบเงินค่าคอมมิชชั่นจริง ถ้าเอาออกยอด
  ค่าคอมฯ จะขยับ) — กำไรแค่ "แถมไปกับ" แถวเดิม ไม่ได้เปลี่ยนว่าแถวไหนถูกนับ
- **คอลัมน์กำไรมี 2 ตัวเสมอ ไม่ใช่ตัวเดียว** — `margin_ex_vat`/`total_margin` (จำนวนกำไร)
  คู่กับ `gmv_with_margin` (ยอดขายเฉพาะแถวที่มีข้อมูลกำไรจริง) ตัวหลังนี้จำเป็น
  เพราะกำไร ฿0 กับ "ไม่มีข้อมูลกำไร" หน้าตาเหมือนกันถ้าไม่มีตัวนี้ช่วยแยก

## หลังรันเสร็จ ยืนยันยังไงว่าใช้ได้จริง

ไม่ต้องรอทีมโค้ด — เปิดแอปแล้วดูได้เลย:

- **Sense**: เข้าหน้าร้านค้าไหนก็ได้ที่มียอดขายเดือนนี้ → การ์ด "ยอดซื้อ" ควรมีบรรทัด
  "กำไร (GP)" โผล่ต่อจากยอดขาย
- **NRR Dashboard**: ล็อกอินแบบ admin → แท็บ **Commission** → จะมีปุ่มสลับ
  "ยอดขาย / กำไร (GP)" เหนือตาราง BREAKDOWN · หรือเข้าแท็บใหม่ **กำไร** (เมนูบนสุด,
  admin เท่านั้น) → เห็นกราฟกระจาย GMV × %GP

ถ้าเข้าไปแล้วยังเห็น "ยังไม่มีข้อมูลกำไร" ทั้งที่รันแล้ว = แสดงว่า CSV ที่อัปโหลด
ยังไม่ใช่เวอร์ชันในแพ็กนี้ ให้เช็คจำนวนคอลัมน์ตามตารางด้านบนอีกรอบ
