## รอบ 2026-08-24 แก้อะไรบ้าง

**อาการ:** บนแดชบอร์ด แถวของเดือนที่ยังไม่ปิดโชว์ชื่อร้านเป็นช่องว่าง หรือเป็นรหัส
UUID ยาวๆ · วัดจากไฟล์จริงบน R2: `vp_view.csv` 2,288 จาก 12,961 แถว (17.7%)
ไม่มีทั้ง `account_name` และ `res_name` · `admin_view` 548 (10.7%) · `pm_view` 314
· `kam_rep_view` 132 — **ทุกแถวเป็นเดือนปัจจุบันล้วน** เดือนก่อนหน้าปกติดี

**สาเหตุ:** ชื่อถูกดึงจาก `order.cdp_account_name` / `cdp_res_name` โดยหยิบจาก
ออเดอร์ล่าสุดของเดือนนั้น (`QUALIFY ROW_NUMBER() ... ORDER BY delivery_date DESC`)
⇒ ถ้างาน CDP ยังเติมชื่อให้ออเดอร์ใหม่ไม่ทัน ชื่อจะว่างทั้งแถว ยิ่งใกล้วันรันยิ่งเจอเยอะ
หลักฐานยืนยัน: 2,259 จาก 2,288 แถวนั้น ร้านเดียวกัน**มีชื่ออยู่แล้ว**ในแถวเดือนก่อน
ของไฟล์เดียวกัน

**แก้:** ให้ `dim.user_master` เป็นแหล่งชื่อหลัก ให้ `cdp_*` เป็นตัวสำรอง (กลับด้าน
จากเดิม) · **ไม่ได้เพิ่ม JOIN ใหม่** — CTE `user_account_type` อ่าน `user_master`
ที่ grain `res_id` อยู่แล้วและถูก join ในชั้นนอกอยู่แล้วสำหรับ `account_type`
แค่ดึงเพิ่ม 2 คอลัมน์ · ใช้ `NULLIF(TRIM(...), '')` เพราะ cdp เขียน `''` บ่อยพอๆ กับ NULL

**โครงสร้าง output เหมือนเดิมทุกคอลัมน์** ไม่ต้องแก้อะไรฝั่งปลายทาง
